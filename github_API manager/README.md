# API 接口管理器

一个简洁轻量的本地 API 接口管理工具，用于保存和管理 API 厂商名、Base URL、API Key 和备注。

## 功能

- 添加接口
- 查看接口目录
- 单击接口查看详情
- 双击接口载入修改
- 保存修改
- 删除接口
- 本地 JSON 保存与读取
- 接口详情可复制

## 使用方式

1. 在右侧填写接口信息
2. 点击“添加接口”保存
3. 单击左侧接口查看详情
4. 双击左侧接口载入修改
5. 修改后点击“保存修改”
6. 选中接口后点击“删除接口”

## 数据保存

程序会在本地生成 `apis.json` 文件，用于保存接口信息。

注意：请不要将真实的 `apis.json` 上传到公开仓库，以免泄露 API Key。
